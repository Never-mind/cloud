# 标签页内重复导航修复（2026-10-29）

## 原因与修复

业务伙伴列表的部分链接未保留 `embed=1`；同时项目使用 `src/app`，旧中间件位于根目录，未进入运行构建，导致 iframe 中的明细被识别成完整工作区。

- 将中间件移至 `src/middleware.ts`，从浏览器请求类型识别 iframe，重定向时保留标签页标记。
- 公共 AppShell 同时检测实际 frame 身份，避免旧链接或刷新产生重复侧栏、标签栏。
- 顶层页面不再被同模块遗留的嵌入 cookie 误判；列表、明细、返回和新建跳转保留查询、分页及标签上下文。
- 新增 `scripts/build-local-release.mjs`：隔离构建并校验产物包含中间件，成功后再切换本地运行版本。

## 巡检附带修复

- 实例型号页的可选 B6 配置未启用时，保留实例维护，不抛出未处理异常。

- 采购单发票信息从采购明细关联需求明细读取供应商，修正查询不存在的主表供应商字段引发的 500；重复发票校验沿用同一关联关系。
