# 导入批量开票

入口：发票管理 → 导入批量开票。本期是本地开票，支持算力服务费、华为云账单和预付款合同。

## 使用步骤

1. 下载最新模板，在“开票导入”工作表填写，一行一张票，最多100行、文件不超过5MB。支持xlsx和xls。导入编号由系统生成，无需填写；模板预填香港万众科技有限公司及税率0，只有默认值的空白行不会导入。
2. 上传并预览。可逐行“修改／分摊”，搜索更换开票客户、开票单位或关联账单。匹配不到、重名、缺少档案、税金不一致、汇率缺失等问题会显示在对应行。
3. 展开“明细”核对分摊、当前未开余额及差额。选中有效行，核对确认后开票。发票成功即绑定账期／合同并累计开票信息，不修改应收、实收或合同核销。
4. 可停止后续处理，当前行完成后停止。每行独立提交，失败不回滚其他已成功行。修正失败行后继续，或通过“恢复最近批次”恢复中断工作。
5. 下载结果表或将已生成发票打包下载。票面使用已有本地开票模板及PDF渲染；运行环境没有可用PDF浏览器时沿用HTML回退。

## 关联、金额与重试

- 服务费：填对账单号；华为云：填`YYYYMM@账号`，或通过页面选择唯一记录；预付款：填合同号。多个账期以分号分隔。同一票的账单需属于同一业务客户；实际开票客户可另选。一张预付款发票关联一份合同，一份合同可开多张票。
- 单账期拆票：多行填写相同关联单据及各票金额，系统分别编号；同表两行内容完全相同也能生成两张票。多账期多票：多行均关联所需账期，分别填写各票金额／分摊。
- 开票单位留空默认香港万众科技有限公司，从业务伙伴档案匹配，可填写其他单位或在预览更换；客户留空仍按来源客户填写。
- 含税金额以客户确认的导入金额为准，0.10等差额会提示而不强制覆盖成系统应收。未税可留空反算，税率使用百分数，留空默认为0；有税时填写实际税率。
- 开票日期留空按上传当天的北京时间填写并保存；跨天继续处理不会自动改成当天。手动填写的日期优先，应收日期按该开票日期及账期计算。
- 默认根据来源含税金额比例分摊，按分计算并处理尾差；也可按关联单据顺序填写“分摊含税金额”，合计必须等于整票金额。
- “业务汇率”方向为`1开票币=N来源币`，预付款来源币为合同币。异币必须明确填写，多账期可分别填写。美元汇率独立为`1 USD=N开票币`。
- 一行汇总描述示例`202512-202605服务费`，票面一行，后台仍分摊至各账期。选择按账期分行时，沿用现有分行描述规则。
- 新模板无需导入编号。系统自动生成稳定标识，相同表格重复上传（包括改名或重新保存）恢复原批次，保留已编辑内容和原开票日期。增加其他行后，未变化的已开票行仍会跳过。确需对相同业务新增相同金额发票时，在原表中增加一行，或填写实际的新开票日期/发票号。旧模板仍兼容原导入编号。确认时重新验证来源及权限；预览依据改变需要重新校验。
- 原有手工汇总但未登记原票的账单、未完成飞书审批占用、不同发票币种，以及预付款超额等约束继续生效。预付款须先确认合同金额口径。
- 已导入发票保留作废记录，不永久删除，防止重新导入重复开票。同批其他待开票行不计入逐行“当前未开余额”，查看整批选中合计和各行金额一起核对。

## 部署

已有预付款财务升级（含`merge_common_invoices.importBatchId/importRowKey`）的基础上执行：

```powershell
npm run schema:invoice-batch-import
npm run schema:invoice-batch-import -- --apply
npm run build
npm run start -- -p 5174
```

只新增2张导入批次／行记录表，应用前保存已有表结构；不改动历史业务记录。使用长连接MySQL命名锁避免批次并发修改及跨批次重复生成；发票、分摊、来源回填、导入编号在既有开票事务中提交。执行结果即使因网络中断未返回，下次按导入编号恢复。

权限：发票管理查看+创建，以及来源模块查看+修改。只能访问本人创建的导入批次。上传阶段只建立预览批次，不生成正式发票；不自动发起飞书审批。

隔离验证：`npm run verify:invoice-batch-import -- --allow-write-test`仅允许localhost/127.0.0.1且库名含local/test，使用随机测试来源并在finally清理；禁止对生产库运行测试开票。
