# 一次审批回传多张发票

2026-11-12：审批节点已上传多个票号时，旧自动登记逻辑因只接受一个发票组而整体停止。PDF/XML已下载识别，但账单仍显示“审批通过待出票”。

## 修复行为

- PDF/XML仍按开票方税号和票号归为一张发票。
- 多张发票逐张与已批准的账期分摊比较币种、未税金额、税金、含税金额和税率。每张唯一对应一条批准明细时分别登记、挂PDF并回填账期。同月不同账号也分别处理。
- 所有待登记发票先完成识别、主体匹配、金额检查和原件读取。金额相同导致无法区分账号、附件不全、识别冲突或需要其他多对多分摊时停止自动登记并提示异常，不推测对应关系。
- 写入事务内锁定审批与回票，重新计算分摊匹配、校验批准金额和汇率，防止重复登记、跨账期或跨票附件误绑。
- 每张发票及账期回填独立事务提交；中途失败后按回票文件的invoiceId跳过已成功的票继续。全部回票完成后才设置审批的代表invoiceId，未完成的审批仍可轮询重试。
- 内部USD折算使用批准分摊的汇率。CFDI票面的本币汇率仍保留在识别原始事实中。
- 华为云列表区分“审批通过待出票”“审批通过，回票待登记”“审批通过，回票异常”和“审批通过已开票”；异常原因在状态提示中显示。
- 无需数据库结构变更；原有每60秒审批同步入口直接使用修复后的逻辑。远程服务需部署本次代码才能获得修复。
