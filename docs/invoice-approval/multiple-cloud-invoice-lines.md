# Cloud Invoice 墨西哥多行开票

2026-11-11

## 行为

- Cloud Invoice 墨西哥分支的“发票信息”支持新增、删除开票明细，每行独立填写含税金额、开票内容和 CFDI 用途码，最多 100 行。
- 单账期也可以拆成多行；多账期可以按账期生成、合成一行，也可以自定义行数。
- 票面行与账期分摊独立。选择多个账期后，已手工填写的开票明细保留。回票按申请中保存的分摊登记到各账期。
- 明细含税合计、整单含税金额、账期分摊合计必须一致；金额支持最多两位小数，逐行可含冲减金额，审批合计必须大于零。
- “使用明细合计”更新整单金额，并按当前税率计算未税和税金；如有分摊，还需核对分摊合计。
- 飞书发票信息 fieldList 按填写内容提交多行；自动附带的合并开票说明同时保留账期分摊和独立“开票明细”工作表。
- 旧单行调用继续兼容；回票金额预期读取全部墨西哥明细的合计。

## 范围

本次修复截图所示的 Cloud Invoice 墨西哥发票信息明细表，公共开票弹窗各业务入口均生效。国内增值税审批金额属于整单字段，智利审批字段结构也不同，本次未修改这两个分支。无需数据库迁移。
