# 对账确认与后续开票、实收维护

适用范围：算力服务费对账单、华为云对账单。

确认只冻结账单业务金额及明细。开票、实收、日期、实际往来主体、相关状态及附件继续维护，不改变原确认信息。

## 实现

- 华为云更新接口采用明确的开票/实收字段范围。已确认账单夹带业务金额、账号、账期、业务归属、确认元数据等字段时整次拒绝。
- 通用更新接口不再接受确认状态赋值，确认和取消确认通过专用接口处理。
- 实收表单只提交实收字段，避免原先按 collection 前缀提交导致的开票状态、账单收款主体误覆盖。
- 更新、删除和导入覆盖已有账单时，在事务中锁定当前行并检查确认状态，避免并发确认后覆盖账单。
- 已确认账单禁止直接删除。账单导入跳过已确认行，返回账期及账号列表并在页面提示；后续开票/实收使用独立编辑入口。
- 开票和实收变更只重算自身税额，不重算应收、应付、毛利，也不触发供应商应付汇总重建。
- 算力服务费现有接口已经允许确认后维护；保留此行为，补充回归验证并统一提示文案。
- 本地开票、上传识别及飞书财务回票使用原有发票回填逻辑，只更新发票字段。审批发起仍与实际开票分开。
