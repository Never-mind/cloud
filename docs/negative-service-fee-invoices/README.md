# 算力服务费负数合并账期开票

更新日期：2026-11-06。已构建并在本地 5174 服务启用。无需数据库结构变更。

## 行为

- 服务费账期选择允许负金额与零金额账单；同业务客户、审批占用、汇率及重复登记校验继续执行。
- 正负账期按各自金额相抵，支持本地生成合计为正数、负数或零的发票；按账期分行和合并为一行均保留后台独立分摊。
- 分摊采用有符号金额和整数分，负数账期保持抵扣方向。原账单金额、税率、币种和回款不被改写。
- 按当前票面总额分摊时，正负原金额之和为零但新总额非零，或总额符号相反时，提示人工核对，避免无依据分摊。
- 外部负数服务费发票可以确认登记。其他模块的负金额限制维持原有行为。
- 飞书审批可以包含负数服务费分摊行，但现有 Cloud Invoice / 国内增值税审批的整票金额仍须大于零；本次未更改远端审批定义或红字审批流程。
- 银行实收不随开票操作登记。
