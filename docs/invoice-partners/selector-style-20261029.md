# 飞书开票双方选择框样式调整

适用：Cloud Invoice Process、增值税开票申请。

- 两个流程共用“开票双方”布局：左侧承接单位，右侧开票客户；窄屏自动换行。
- 选择框全宽、等高，统一搜索图标、下拉箭头和聚焦边框。
- 下拉等宽，长名称换行，名称与辅助说明相同则只显示一次；选中项使用浅蓝底和勾选。
- 增值税表单的飞书主体和 CLOUD 组改为下方只读说明，避免与可选字段混排。
- 支持按名称、编码及税号搜索；保留既有伙伴切换及信息带入逻辑。
- 新样式仅用于两个审批表单，通过 SearchSelect 的 partner 外观启用；下拉挂载到 body，避免弹窗内容区裁切，并补偿系统 html 90% 缩放。
