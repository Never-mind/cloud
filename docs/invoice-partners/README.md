# 开票业务伙伴选择

本次开发支持在开票时选择实际开票双方，并从业务伙伴档案带入相应资料。业务账单仍保留原客户、承接单位和供应商归属。

## 使用范围

| 入口 | 可选择的档案 | 带入的资料 |
| --- | --- | --- |
| 算力服务费、华为云对账、项目结算的本地开票和上传识别确认 | 客户、承接单位 | 客户抬头、税号、地址、联系方式；开票单位名称、地址、联系方式、银行账户、账期 |
| Cloud Invoice Process | 客户、承接单位 | 客户开票资料、客户附件候选、飞书主体分支、账期和约定收款日 |
| 增值税开票申请（专票/普票） | 客户、承接单位 | 中文抬头、税号、地址、电话、开户行、账号；匹配的飞书主体、账期 |
| 服务费对账单的编辑开票、编辑实收 | 客户、承接单位 | 更新对应的实际开票方、收付款方字段 |
| 华为云供应商付款 | 供应商 | 单独保存实际开票供应商编号和当时名称 |
| 项目结算发票手工登记 | 收入选客户，成本选供应商；承接单位独立选择 | 更新本张发票的主体信息 |

搜索支持名称、简称、英文名、编码、税号，选中后显示名称。资料自动带入后仍可手工修改；本次修改保存到发票或审批记录，不回写业务伙伴档案。

## 关键规则

- 切换客户后清除旧客户资料和已选旧客户档案附件，保留账单/项目附件及本次上传文件。
- 新档案没有维护的字段留空，避免沿用上一家公司的资料。多银行账户未设唯一默认账户时不任意选择，用户可补充本次资料。
- 切换开票主体后重新匹配飞书公司和账期；飞书流程没有相应主体时阻止提交并显示原因。
- 资料读取期间或读取失败时禁止提交。Cloud Invoice 和增值税资料读取失败都会恢复原有效选择，后续切换或刷新不会混用客户编号和旧资料。
- 增值税仍使用人民币开票；来源账单可以是其他币种，人民币金额由用户确认。
- 飞书审批保存实际开票双方资料快照。回票与审批选择的主体比较，确认登记优先采用匹配的票面识别信息；识别有歧义时仍需人工选择。
- 本地正式发票及重新生成文件使用已保存资料快照，后续档案改名不会重写历史开票资料。
- 华为云供应商开票方独立于付款账期的业务供应商。首次按默认供应商登记发票时同样保存名称快照。

在项目目录读取计划（只读）：

```powershell
node --env-file=.env.local --import tsx scripts/migrate-invoice-partners.ts
```

确认目标数据库并安排部署后应用：

```powershell
node --env-file=.env.local --import tsx scripts/migrate-invoice-partners.ts --apply
```

注意 `.env.local` 当前指向生产库，以上第二条命令会修改生产表结构。不能先运行新版本再补字段，否则供应商付款列表查询和审批提交会失败。

代码回退时可以保留新增的可空字段；不要删除已产生的审批快照或供应商发票归属数据。
