# 华为云供应商跨账期付款与发票

实现范围：列表跨页多选；同供应商/付款单位/币种合并发起一张飞书审批；保存每期含税、未税、税率、税金、汇率；确认付款节点后一次性回写，重复同步不覆盖后续人工修改。支持独立登记同一供应商发票在多个账期的分摊及共享附件。

使用现有审批 allocationPlanJson 保存带版本的付款快照；不改变历史审批的回写口径。生产业务数据不用于写入测试，不发起测试审批。运行验证使用隔离测试和只读页面请求。

使用：华为云对账 → 供应商付款 → 勾选多个账期 → “合并发起付款”。核对各期本次付款金额、币种、账户及附件，再提交一张飞书审批。支持更改付款成本项目，回写目标仍是原华为云账期。

共用一张供应商发票时，在同一列表勾选账期 → “发票跨账期分摊”。上传并识别或者选择所选账期已有附件，确认整票信息后按应付比例分摊，也可手动调整每期金额，合计必须等于整票。该操作不修改实付金额。

分摊采用整数美分及最大余数法；税金/未税合计和含税合计均校验。单期编辑可保存未改变的共用发票字段及付款信息，调整共用发票金额/税率/日期需在分摊入口统一完成。

部署：复用已有审批的 LONGTEXT allocationPlanJson 及 TEXT allocationSourceIds，无新增表。付款自动同步继续运行；新申请仅在财务确认到账节点完成后登记实付，写回失败保留重试，成功后不重复覆盖。历史没有分摊计划的审批保持原口径。
