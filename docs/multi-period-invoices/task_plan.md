# 多账期发票闭环实施计划

## 目标
华为云、算力服务费统一支持：外部发票一次识别关联多个账期；本地、Cloud Invoice、增值税审批合并开票；按月分行或汇总一行；回票确认按各期分摊回填。保留实际开票双方可替换及 USD 账单/CNY 开票。

## 约束
- 保留当前工作区所有历史未提交改动。
- 不提交真实审批，不用生产业务数据做写入测试。
- 同一张票只记一次；调整关联必须复用原票、展示完整分摊变化。
- 票面行与分摊行分开；金额按分校验；审批保存金额快照。
- 服务仍使用 5174；构建完成后用带远程只读检查的启动方式激活。
